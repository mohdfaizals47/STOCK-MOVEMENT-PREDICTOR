# STOCK-MOVEMENT-PREDICTOR


📈 Stock Movement Predictor

A machine learning web application built with Streamlit that predicts whether a stock price will go UP 📈 or DOWN 📉 the next day using Ensemble Learning (Random Forest).

🚀 Features
📊 Predicts next-day stock movement (UP / DOWN)
🤖 Uses Random Forest (Ensemble Learning)
🎯 Simple user input interface
⚡ Fast predictions using a pre-trained model
🎨 Clean UI with custom styling and animations
🧠 Machine Learning Model

The prediction model is trained using Ensemble Learning techniques, specifically:

Random Forest Classifier
Feature inputs:
Closing Price
Trading Volume
Daily Returns (%)
10-Day Moving Average
50-Day Moving Average

The training process and experimentation are available in:
👉 Ensemble_Learning_Techniques.ipynb

🖥️ Application Interface

The app is built using Streamlit and allows users to:

Enter today's market data
Click Predict Movement
View prediction result:
🚀 UP (with animation)
📉 DOWN

Main app file:
👉 app.py
